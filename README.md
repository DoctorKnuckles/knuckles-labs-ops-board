# Knuckles Labs Ops Board (tablet kiosk)

Always-on shared home screen for Steve's rooted tablet.

## Files
- `index.html` — the board
- `manifest.json` — fullscreen PWA shell

## Install on the tablet (plain English)
1. Plug the tablet in and leave it charging.
2. Developer options → **Stay awake** (screen stays on while charging).
3. Open `index.html` in Chrome (copy the folder to the tablet, or host it on the shared computer / Drive and open the link).
4. Add to Home screen / open fullscreen so it fills the display.
5. Optional with Magisk: lock the device to this one app (kiosk) so Candy Crush never appears.
